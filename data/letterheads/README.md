# Fund letterheads

Default artwork is cropped from the official Fund 1 stationery PDF
(`fund_1_source.pdf`):

- A4 body with a 3.75 cm top margin and a 2.75 cm bottom margin
- Logo, black bar, red bar, address, and footer taken from that file
- Other funds keep the same layout and only change the fund name/address

Operators can drag, select, and drop the header and footer strips on the page.
